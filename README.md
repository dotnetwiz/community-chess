# Community Chess

Community Chess is standard chess played by teams. Each team shares one color, but its players take turns making moves in a defined rotation. Teammates cannot communicate or coordinate, so every player must read the board and act independently.

The first format will be a single-board 3v3 game: three players per side, one shared chessboard, and no in-game teammate communication. A later relay mode may run three games at once, with player order staggered between boards.

Project status: game concept development; no implementation yet.
